# nuée — Radiance Serum

A one-page, full-screen product story for the fictional skincare brand **nuée**. The serum bottle stays on
screen while four scenes change around it: misty lake hero → ingredients ring → hand with three benefits →
dark room with the bottle on a pedestal. Each wheel flick, swipe or arrow key plays one transition.

Open `index.html` in a browser (or serve the folder). `window.nuee.go(n)` jumps to scene `n` (0–3).

- `assets/nuee-serum.webp`: transparent cutout of the bottle
- `assets/nuee-serum-photo.jpg`: original product photo (used for benefit thumbnails)
- `SOURCES.md`: research behind the ingredient and benefit copy
